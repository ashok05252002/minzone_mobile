# MINZONE.EV — Mobile App Prototype
Clickable prototype of the MINZONE.EV driver app (login, Explore map, station details, payment, live charging, receipt, wallet, history, profile).

Static site — no build step. Deploy on Vercel: Add New → Project → import this repo → Framework "Other" → Deploy.
Local preview: `npx serve .`
